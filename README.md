# DotaMemos - 回忆卡片 🎬

电影级视觉体验的Dota情怀卡片应用

## 项目结构

```
Frontend/
├── miniprogram/

├── tsconfig.json
```

## 核心功能

### ✨ 电影级视觉效果

1. **开场动画**（2.8秒）
   - 渐变遮罩滑动（从MyTravelMemos复用）
   - 模糊到清晰的转场
   - 缩放+亮度变化

2. **电影遮罩**（上下各15%）
   - 黑色渐变遮罩，营造影院感
   - 上遮罩：从纯黑到透明
   - 下遮罩：从纯黑到透明

3. **文案动画**（优雅分段显示）
   - 标题：1.5s后淡入上移（1.2s动画）
   - 第一段：2.2s后淡入上移（1.4s动画）
   - 第二段：3.0s后淡入上移（1.4s动画）
   - 每段文字都有轻微的向上飘动效果

4. **图片显示**
   - aspectFit模式（竖屏图片完整显示）
   - 上下自然留黑（配合电影遮罩）
   - 轻微缩放动画增强沉浸感

## 使用方法

### 1. 添加测试图片

请将你的测试图片 `00.jpg` 复制到：

```
miniprogram/assets/images/void_01.jpg
```

或者在命令行执行：

```bash
copy "D:\Developments\dota memos\01 Material\pictures\00.jpg" miniprogram\assets\images\void_01.jpg
```

### 2. 安装依赖

```bash
npm install
```

### 3. 在微信开发者工具中打开

1. 打开微信开发者工具
2. 导入项目：选择当前目录（`D:\Codes\WechatMini\DotaMemos\Frontend`）
3. 编译并预览

## 视觉效果时间轴

```
0.0s  ─── 打开小程序，黑屏
0.3s  ─── 开场动画开始（渐变遮罩滑动 + 模糊到清晰）
1.0s  ─── 渐变遮罩开始滑出
1.5s  ─── 标题开始淡入（"五秒钟的虚空"）
2.2s  ─── 第一段文案淡入
2.7s  ─── 标题完全显示
3.0s  ─── 第二段文案淡入
3.6s  ─── 第一段文案完全显示
3.8s  ─── 开场动画结束，进入静态展示
4.4s  ─── 所有文案完全显示
```

总动画时长：约4.5秒
用户完整体验时长：5-10秒（包括阅读时间）

## 技术亮点

### CSS动画设计

1. **缓动函数**：`cubic-bezier(0.16, 1, 0.3, 1)`
   - 模拟真实物理运动
   - 开始缓慢加速，结尾轻柔停止
   - 带来高级的"重量感"

2. **多层动画叠加**
   - Swiper层：模糊+缩放+透明度
   - 图片层：亮度+缩放
   - 文字层：透明度+位移
   - 遮罩层：滑动+透明度

3. **时间编排**
   - 精心设计的延迟时间
   - 确保视觉焦点依次展现
   - 避免信息过载

### 电影级遮罩

- 使用多层渐变实现自然过渡
- 上遮罩：180度线性渐变（从上到下）
- 下遮罩：0度线性渐变（从下到上）
- 渐变断点：0%纯黑 → 30%深黑 → 60%半透明 → 100%完全透明
